    界面

    主色应用于发送按钮与用户消息气泡，点击色块即时切换。
    消息正文字号（12~20px），默认 14px；行内代码与代码块随之缩放。

    推理参数

    尚未选择对话。打开一个会话/发送一条消息后，这里可查看与编辑该会话的五层记忆。

    ⓪ 系统提示词

    在这里规定LLM的行为边界与输出格式，不随剧情推进而改变。
    保留最近 N 轮对话（一轮 = 一次提问 + 一次回答）。
    N = 0 表示全量模式，按模型窗口尽可能多地保留，但会增加token消耗。

    ① 核心设定

    世界卡

    在这里描述世界观与背景设定。点击列表中的世界卡进行编辑。
    导入支持 JSON（{name, content} / 数组 / {worlds:[...]}）与纯文本文件。

    人物卡

    在这里描述人物设定，点击列表中的角色卡进行编辑。
    带 ★ 的主角色是 AI 第一人称扮演的角色，选中其他卡后点 ★ 可切换主角色。
    导入支持 JSON（{name, content} 或数组）与纯文本文件。

    ② 动态关键事实

    开启时每轮对话后由LLM自动抽取事实并去重，关闭后仅支持「重新总结」和手动编辑。
    在这里存储随时间变化的重要信息，用户可手动修正。
    按住左侧手柄拖拽来调整顺序；上锁的条目不会被「重新总结」覆盖。
    每片上限 = 每个切片最多抽取的事实条数，0 = 不限制。

    ③ 剧情摘要

    开启时每积累 N 轮（切片轮数）自动总结一次剧情；关闭后仅支持手动「重新总结」和编辑。
    在这里存储对话内容梗概，每积累 N 轮（切片轮数）自动总结一次；「重新总结」从全部历史重新生成整份文本。
    分页选择即注入模式：当前所在分页决定对话时注入哪种摘要——文本摘要注入整份文本，切片摘要注入按场景切片拼接的内容。打分场锚点后自动总结会按场景落袋切片。

    ④ 向量记忆

    长对话检索具体对话细节用的本地模型（后端 models 目录）。
    0 = 自动召回（按相似度阈值，不限数量）；>0 = 固定返回前 N 条相似记忆（上限 500）。
    切片管理
    已总结落袋的剧情切片（按剧情顺序）。展开可查看本片对话内容、编辑场景名与本片摘要；改名与消息分割线双向同步。
    开启时每标记一个锚点即自动总结前一个切片；关闭时不自动总结，仅支持手动「重新总结」和编辑。
